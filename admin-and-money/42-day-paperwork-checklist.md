## If it slips — the fallback (know it before you need it)

- **Passport late, Special Pass expiring within 7 days:** (MOM, verified 27 Oct 2026) request an **extension of the Special Pass** via MOM's newborn extension form — submit *only* when the ICA Advisory Note is expiring within 7 days (i.e. from ~Mon 30 Nov for a 7 Dec expiry). If Eldric is instead already holding a **MOM-issued** Special Pass, it auto-extends 28 days if the DP isn't ready (SMS to the registered mobile one day before expiry) — no request needed.
- **No DP route at all:** ICA Visitor Services Centre (Level 4) in person, with Eldric, before expiry.
- Escalation order if HR/employer stalls: Eric chases HR → HR contacts MOM newborn expedite → ICA extension as the safety net. A stalled DP at Day 35 with no extension filed is the failure mode; everything above exists to prevent exactly that.
